# Article drafts

Put Markdown drafts in this folder. The current starter does not yet convert these files into published pages automatically; that can be added later with an MDX/Markdown pipeline or CMS.

Suggested front matter for future use:

---
title: "A working title"
date: "2026-10-23"
summary: "A short description"
tags: ["research", "music"]
---

Remember to verify facts and permissions for quotes, images, and source material.
